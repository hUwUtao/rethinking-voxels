QUICK START GUIDE

1. Install Prerequisites
   ✓ Fabric Loader 0.18.4+
   ✓ Fabric API 0.136.1+ (for MC version)
   ✓ Iris Shaders 1.8.8+
   ✓ StudioLight Fabric mod (../studiolight)

2. Deploy Shader Pack
   • Copy rethinking-voxel-patched/ to shaderpacks/
   • Select in Iris Shaders menu (In-Game Settings > Shaders)
   • Game should recognize: "Rethinking Voxels w/ StudioLight"

3. Create Your First Light
   /studiolight spawn point ~5 ~2 ~5 my_light
   /studiolight set my_light param intensity 0.8

4. Visualize
   • Gizmo sphere appears at light position
   • See real-time lighting feedback in deferred pass
   • Adjust with `/studiolight set` commands

TECHNICAL HIGHLIGHTS

• Zero-cost abstraction: No performance penalty when mod is not loaded
• SSBO (Shader Storage Buffer): Up to 256 lights, 80 bytes each = 20 KB
• Precision: Camera-relative coordinates prevent float degradation
• Interop: Mod writes SSBO each frame; shader reads during deferred pass
• Extensibility: Modular functions for custom light types

Light Type Evaluation:
─────────────────────
Point:  distance-based attenuation (windowed inverse-square)
Spot:   attenuation + cone mask with physical slit penumbra
Area:   sphere proxy attenuation + barn door half-plane clipping
